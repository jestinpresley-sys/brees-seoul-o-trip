# Bree's Seoul-o Trip 🍂

A cozy, Stardew-style pixel game replay of Bree's week in Seoul (Oct 10–16, 2026).

Walk around one connected Seoul — Jongno, Gyeongbokgung, Cheonggyecheon, Hongdae, Myeongdong, Seongsu, Namsan, the Han River, Yangjae and Jamsil — and play through each day of the trip.

**Play:** open `index.html` in a browser, or visit the GitHub Pages site.

- Phone: D-pad + A/B buttons, or tap to walk
- Desktop: WASD/arrows to move, Space/Enter to talk, Shift to run, P plan, M map, J scrapbook

Single-file HTML game — no build step, no dependencies.
